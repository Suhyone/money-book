# สมุดรายรับรายจ่าย (money-book)

เว็บแอป (PWA) บันทึกรายรับรายจ่าย ใช้ได้ทั้ง iPhone และ Android ฟรี 100%

- ไม่มี server และไม่ต้องซื้อโดเมน ตัวเว็บฝากไว้บน GitHub Pages ส่วนข้อมูลอยู่ในมือถือของแต่ละคน
- ติดตั้งลงหน้าจอโฮมได้เหมือนแอป และใช้งานออฟไลน์ได้
- ฟีเจอร์: บันทึก/แก้/ลบ, หมวดหมู่ปรับแต่งได้, สรุปรายเดือนพร้อมกราฟ, งบประมาณต่อหมวด (เตือนเมื่อใช้ถึง 80% และเมื่อเกินงบ), รายการประจำ (รายสัปดาห์/เดือน/ปี), สำรองและกู้คืนข้อมูล (.json), export ไปใช้ใน Excel (.csv)

## ใช้งานบนมือถือ

| เครื่อง | วิธีติดตั้ง |
|---|---|
| iPhone / iPad | เปิดลิงก์ใน **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** |
| Android | เปิดลิงก์ใน **Chrome** → กด **ติดตั้งแอป** (หรือเมนู ⋮ → เพิ่มลงในหน้าจอหลัก) |

หลังติดตั้งให้เปิดจากไอคอนเท่านั้น ครั้งแรกต้องมีเน็ต หลังจากนั้นใช้ออฟไลน์ได้

## ⚠️ เรื่องข้อมูลที่ต้องรู้

- ข้อมูลอยู่ในเครื่องนั้นเท่านั้น ไม่ได้ส่งขึ้น server ไหนเลย
- **iPhone:** ข้อมูลในแอปที่ติดตั้งแยกจากข้อมูลใน Safari และถ้า**ลบไอคอนแอป ข้อมูลจะหายด้วย**
- ควรสำรองข้อมูลเป็นระยะ: **เพิ่มเติม → สำรองข้อมูล (.json)** แล้วส่งเข้า LINE ตัวเองหรือเก็บใน Google Drive (แอปจะเตือนถ้าไม่ได้สำรองนานเกิน 30 วัน)
- **เปลี่ยนมือถือ:** สำรองจากเครื่องเก่า → ในเครื่องใหม่ไปที่ **กู้คืนจากไฟล์สำรอง → แทนที่ข้อมูลในเครื่องทั้งหมด**
- **ห้ามเปลี่ยนที่อยู่เว็บ** (โดเมนหรือผู้ให้บริการ hosting) เพราะข้อมูลผูกกับที่อยู่เว็บ ถ้าจำเป็นต้องย้ายจริง ให้ทุกคนสำรองข้อมูลจากที่เดิมก่อน แล้วไปกู้คืนที่ใหม่

## พัฒนาในเครื่อง

ต้องมี Node.js 22.18 ขึ้นไป หรือ 24.12 ขึ้นไป

```sh
npm install
npm run dev            # เปิด http://localhost:5173 แก้โค้ดแล้วหน้าเว็บอัปเดตทันที
npm test               # unit tests
npm run build          # ตรวจ type + build ลง dist/
npm run preview        # เปิดไฟล์ที่ build แล้วที่ http://localhost:4173 (ทดสอบ PWA/ออฟไลน์)
npm run lint
npm run format
npm run generate-icons # สร้างไอคอนใหม่ หลังแก้ public/logo.svg
```

> Service worker (ออฟไลน์ / แถบ "มีเวอร์ชันใหม่") ทำงานเฉพาะตอน `build` + `preview` หรือบนเว็บจริง ไม่ทำงานใน `npm run dev`

## Deploy ขึ้น GitHub Pages (ครั้งแรก)

1. สร้าง repo แบบ **Public** บน GitHub ชื่อ `money-book` (ไม่ต้องติ๊กสร้าง README)
2. ใน repo ไปที่ **Settings → Pages → Build and deployment → Source** แล้วเลือก **GitHub Actions**
3. ในโฟลเดอร์โปรเจกต์ (แทน `<username>` ด้วยชื่อบัญชี GitHub):

   ```sh
   git remote add origin https://github.com/<username>/money-book.git
   git push -u origin main
   ```

4. ดูความคืบหน้าที่แท็บ **Actions** เสร็จแล้วจะได้ลิงก์ `https://<username>.github.io/money-book/` ส่งลิงก์นี้ให้คนในกลุ่มได้เลย

repo ต้องเป็น Public ถึงจะใช้ GitHub Pages ได้ฟรี โค้ดถูกเปิดเผยได้ไม่เป็นไร เพราะไม่มีข้อมูลการเงินของใครอยู่ในโค้ด

## อัปเดตเวอร์ชัน

1. แก้โค้ด → `npm test` → `npm run build` ให้ผ่าน
2. `git commit` แล้ว `git push`
3. รอราว 1–2 นาที ทุกคนที่เปิดแอปจะเห็นแถบ **"มีเวอร์ชันใหม่ของแอป"** กด **อัปเดต** ได้เลย ข้อมูลไม่หาย

ถ้าอยากให้หน้า "เพิ่มเติม" แสดงเลขเวอร์ชันใหม่ ให้รัน `npm version patch` ก่อน push

## แก้โครงสร้างข้อมูลอย่างปลอดภัย

ข้อมูลของผู้ใช้อยู่ใน IndexedDB ของเครื่องนั้นๆ ([src/db/db.ts](src/db/db.ts)) ถ้าจะเพิ่มฟิลด์หรือ index:

- **ห้ามแก้ `db.version(1)` ที่ปล่อยใช้งานไปแล้ว**
- ให้เพิ่มเวอร์ชันใหม่ต่อท้าย พร้อมแปลงข้อมูลเก่าใน `upgrade()` เช่น

  ```ts
  db.version(2)
    .stores({ transactions: 'id, date, categoryId, recurringId, walletId' })
    .upgrade((tx) =>
      tx.table('transactions').toCollection().modify((t) => {
        t.walletId = 'cash'
      }),
    )
  ```

- ถ้ารูปแบบไฟล์สำรองเปลี่ยน ให้เพิ่ม `BACKUP_VERSION` ใน [src/db/backup.ts](src/db/backup.ts) แล้วแก้ `parseBackup` ให้รับไฟล์เวอร์ชันเก่าได้ด้วย

## โครงสร้างโปรเจกต์

```
src/
  lib/          ฟังก์ชันล้วน (เงิน, วันที่ พ.ศ., รายการประจำ, งบ, สรุป, CSV) + เทสต์ใน __tests__
  db/           ชั้นข้อมูล Dexie/IndexedDB (รายการ, หมวด, งบ, รายการประจำ, สำรอง/กู้คืน) + เทสต์
  composables/  useLiveQuery (ข้อมูลเปลี่ยน → หน้าจออัปเดตเอง), toast, PWA, เดือนที่เลือก ฯลฯ
  components/   ชิ้นส่วน UI (แถบเมนู, ตัวเลือกหมวด, กราฟ ฯลฯ)
  views/        หน้าจอแต่ละหน้า
  router/       เส้นทางหน้า (ใช้ #/ เพราะ GitHub Pages)
public/         โลโก้และไอคอน
.github/workflows/deploy.yml   push แล้ว deploy อัตโนมัติ
```

เงินทั้งหมดเก็บเป็น **สตางค์ (จำนวนเต็ม)** เช่น 125.50 บาท = `12550` เพื่อกันปัญหาทศนิยม ส่วนวันที่เก็บเป็นข้อความ `YYYY-MM-DD`

## ถ้าอนาคตอยากให้ sync หรือแชร์ข้อมูลกันได้

เพิ่ม backend ฟรีอย่าง Firebase (Firestore + Authentication) ได้ โดยแก้เฉพาะไฟล์ใน `src/db/` เพราะหน้าจอทั้งหมดเรียกข้อมูลผ่านชั้นนี้
